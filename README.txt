haruta bakery（ハルタベーカリー）サイト（制作デモ / 非公式）
=============================================================

【これは何】
  福岡県久留米市・八女市のパン屋「haruta bakery」向けに、提案用として
  自動生成したデモサイトです。店主の確認・許諾は取れていません。
  このまま公開しないでください。

【選定・依頼の経緯】
  ・ユーザー依頼。公式は Instagram（@harutabakery）中心で、自前HPが見当たらない。
  ・参考サイトとしてユーザーから https://painstock.theshop.jp/ の指定あり。
    「マイショップ（フォーム中心）の形式ではなく painstock の形式で、バナー位置なども」との要望。
    → painstock の縦の構成をなぞった（文章・画像は一切コピーしていない）：
      1. 最上部に閉じられる「お知らせバー」（×ボタン付き）
         ※その上に、当サイト専用の固定「制作デモ」帯（消せない）
      2. ヘッダー：ロゴ左／最小限ナビ／右にカート型アイコン（＝「取り置き」ボタン）
      3. フルワイドのヒーローバナー：中央にJP＋ENタグライン＋ボタン
      4. Our Policy：画像 左／テキスト 右／「More →」リンク（見出し左寄せ）
      5. 商品グリッド：3列・画像 上/名前・価格 下・楕円バッジ・「もっと見る」で6→全件
      6. 店舗
      7. 取り置き予約（painstock のカート/決済に相当する枠をデモ用に置換）
      8. フッター：ロゴ／ナビ／SNSアイコン（IG・FB、リンク未設定）／コピーライト・左寄せ

【デザインの方向性】
  ・ミニマル / エディトリアル / ニュートラル。paper white ×  taupe、アクセントは
    「パンの焼き色」1色のみ。見出しは Zen Old Mincho（明朝・軽め）、本文は細めサンセリフ。
  ・大きな余白、罫線ベースのレイアウト、Latin 小見出し。
  ・既存3件（ゆ鳥＝クリーム丸ゴシック / 大久良＝夜ダーク筆 / ろっぽんぽん＝和ポップ）
    および myshop（角丸ゼロ）とも別方向。

【2店舗対応】
  ・予約フォームの受取店舗は「久留米店 / 八女店」の2択（myshop の2店舗方式を流用）。
  ・submit.php の店舗バリデーションも ['久留米店','八女店'] に変更済み。

【フォルダ構成】
  index.html          … サイト本体（1ファイル完結。CSS埋め込み、写真はSVG仮）
  submit.php          … ご注文フォームの受信処理（PHP）
  config.sample.php   … 設定テンプレート → config.php にコピー
  .gitignore          … config.php / orders.log などを除外
  images/README.txt   … 実写真を入れる場合の置き場メモ

【注文の確認方法（submit.php）】
  送信されると：
   1. orders.log に1件ずつ JSON 追記（バックアップ・全件見返せる）
   2. 店舗あてメール通知（config.php の mail_to）／LINE通知（line_token 設定時）
   3. お客さまあて自動確認メール
        - config.php に mail_to があり、かつフォームにメールアドレス入力があれば送信
        - 差出人は mail_from（未設定なら mail_to）、差出人名は shop_name
        - 件名「【haruta bakery】ご注文を受け付けました（日付 時間）」＋ 注文内容の控え
   ※ PHP が動くサーバーが必要。レンタルサーバーの mail() が飛ばない場合は LINE か SMTP へ差し替え。
   ※ フォームのメールアドレス欄は必須（備考のみ任意）。

【トップバー / フッターの Instagram】
  店舗の公開アカウント https://www.instagram.com/harutabakery2026/ への外部リンク（別タブ）。
  ハンドルは店舗提供の資料に記載のもの。実制作時に正誤を要確認。

【公開する場合の手順（店の了承を取ってから）】
  1. 下の「要確認リスト」を店主に確認し、index.html のダミー値を差し替え
  2. デモ帯・フッターの「制作デモ（非公式）」注記を公開版に差し替え／削除
  3. <meta name="robots" content="noindex, nofollow"> を削除
  4. config.sample.php を config.php にコピーし、LINEトークン or 通知メールを設定
  5. PHPが動くサーバーの公開フォルダにアップロード
